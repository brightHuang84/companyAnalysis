# 微软产品线：份额、订阅、单价

截止 2026-09-07。对象仍是 Microsoft 10-K 做不到的那一层：Windows / Azure / Xbox 没有单品营业利润。这次把年报和网上能找到的**份额、订阅/席位、单价**按年列出来。

页：`docs/products.html`。数据：`data/issuers/MSFT/product_lines.json` 的 `operating` 段，由 `listed_trust/enrich_product_lines.py` 写入。

## 年报到底给什么

| 想要的 | 10-K 实际给的 |
| --- | --- |
| 产品每年营收 | 有。`Revenue classified by significant product and service offerings`，FY2016 起 |
| 产品每年营业利润 | 没有单品。2016 起只有三个分部 |
| 每年席位 / 订阅 | KPI 给**同比增速**。绝对席位多数年份只在业绩会口头报一次 |
| 每年单价 | 没有美元标价。MD&A 只说「average revenue per user expansion」 |
| 每年市场份额 | 没有表。Item 1 写「grow our share of the PC market」，不给百分比 |

所以年表里三类来源必须分开：10-K、业绩会、价目表 / 第三方。

## 订阅 / 席位

商业席位同比（10-K / 业绩 KPI，财年末）：

FY2015 74% → FY2016 45% → FY2017 31% → FY2018 29% → FY2019 23% → FY2020 15% → FY2021 17% → FY2022 14% → FY2023 11% → FY2024 7% → FY2025 6% → FY2026 6%。

公司报过的绝对席位：

- 2017-04：Office 365 商业 1.00 亿
- 2019-10：2.00 亿
- 2021-12：3.00 亿
- 2023-04：3.82 亿
- 2024-01：超过 4.00 亿
- FY2026 Q2：超过 4.50 亿（上季约 4.46 亿）
- FY2026 Q4：只报 +6%，不再报总数；按半年粗算约 4.64 亿

消费订阅：2021-04 超过 5000 万；FY2025 8900 万（+8%）；FY2026 Q1 超过 9000 万；Q3 nearly 9500 万。FY2026 Q1 起这项从 KPI 拿掉，Q4 10-K 仍写消费订阅 +7%。

Copilot 付费席位（业绩会，10-K 不单列）：Q2 1500 万 → Q3 超过 2000 万 → Q4 超过 3000 万。相对约 4.50 亿商业席位，渗透大约 6–7%。

Game Pass：公司最后一次给数是 2024-02 的 3400 万。FY2026 10-K 只说 Game Pass 增长部分抵消内容下滑。2026-07 媒体约 3000 万，未官宣。

## 单价

10-K 没有 SKU 价目表。公开标价（美元 / 用户 / 月）：

- Microsoft 365 E3：2017 约 $32 → 2022-03 $36 → 2026-07 $39
- Microsoft 365 E5：长期 $57 → 2026-07 $60
- Copilot 企业附加：2023-11 起 $30，2026 未涨；叠在 E3 上全包 $69，叠在 E5 上 $90
- Game Pass Ultimate：2019 $14.99 → 2023 $16.99 → 2024 $19.99 → 2025-10 $29.99 → 此后回调约 $22.99
- Azure、Windows OEM：没有单一单价

混合 ARPU（营收 / 席位，倒推，不是标价）：FY2024 约 $16/月，FY2026 约 $19/月。比 E3 标价低，因为里面有大量 F 系列和中小企业 SKU。

## 份额

年报没有份额表。

- Windows 桌面流量：Statcounter，2016 约 83% → 2026-08 测得 62.7%（Unknown 类别升高，真实使用可能被低估）
- Azure 云基础设施：Synergy，2018 约 13% → 2022 约 23% → 2026 Q2 20%（AWS 28%，Google 15%）
- Bing 全球搜索：Statcounter，长期 3–4%，2026-07 约 4.3%；Google 约 91%。FY2026 Q3 公司称 Bing 月活第一次到 10 亿

## 仍缺的

- Azure / Windows / Xbox / Copilot 单品营业利润（年报没有，网上也没有可靠拆表）
- 每年 Game Pass 订阅（2024-02 之后公司不报）
- 每年 Windows OEM 合同单价
- Copilot 实际成交 ARPU（只有标价和席位）
