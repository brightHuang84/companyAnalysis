# 微软（NASDAQ: MSFT）事件优先分析
截止 2026-09-07。财务数字来自微软 FY2026 Q4 业绩稿（截至 2026-06-30）与 SEC 10-K；事件来自公司公告、路透/TechCrunch、欧盟委员会、FTC 公开文件。财务报告只作核验，不是主证据。

四十年编年见 `reports/MSFT_40year_ledger_2026-09-07.md`。91 条逐条「背景 / 原因 / 决策目录 / 效果」见 `reports/MSFT_event_decisions_1986_2026.md` 与 `data/issuers/MSFT/events_1986_2026.json`。下文偏近期核验与打分。

## 总评

- **可信度 64（中）**：云与办公软件的交付大体兑现；对监管、游戏并购、Windows AI 的公开说法多次被后续行为修正。模式是「先铺开、遇阻再收回」，不是「先说清边界再做」。
- **可持续 71（中高）**：Azure 首次全年超过 1000 亿美元、商业剩余履约义务 6780 亿美元，账本极强。风险在员工连续收缩、消费端 Windows/Xbox 失血、OpenAI 排他被拆掉后的模型供给。

七维（事件加权，不是财报公式）：经营模式 84，行为准则 61，董事会 76，管理文化 58，员工 46，消费者 54，用户 53。

## 经营模式：项目进展

Nadella 2014 年上任后的主线是「移动优先、云优先」变成「云 + AI」。FY2026 营收 3318 亿美元（+18%），营业利润 1552 亿美元（+21%）。智能云 1378 亿美元；Azure 及其他云服务全年 +41%，首次超过 1000 亿美元。微软云全年 2144 亿美元。Office/M365 商业云仍是现金牛；LinkedIn FY 增速 11%。

对照项目：

| 项目 | 承诺/定位 | 进展（核验） | 状态 |
| --- | --- | --- | --- |
| Azure | 第二云、AI 工厂 | FY26 超 1000 亿美元，Q4 +43% | 兑现且超预期 |
| Microsoft 365 Copilot | 办公 AI 收费席位 | FY26 末付费席位超 3000 万 | 商业端兑现 |
| GitHub Copilot | 开发者入口 | 5000 万用户 | 用量兑现；版权诉讼未闭环 |
| OpenAI 联盟 | Azure 独占 API | 2026-04 重订约，OpenAI 可上 AWS/GCP | 排他承诺被拆，投资收益仍在账上 |
| Activision/Xbox | 缩小与索尼差距 | 2023-10 交割 690 亿美元；之后连续裁员、关工作室；FY26 Q4 Xbox 内容与服务 -10% | 战略未兑现 |
| Copilot+ PC / Recall | 每台 Windows 都是 AI PC | 2024 被迫推迟 Recall；2026-01 报道收缩 Copilot 铺量 | 消费端项目受挫 |
| Anthropic 投资 | 对冲 OpenAI | FY26 Q4 确认 32 亿美元投资收益 | 多模型对冲属实 |

个人计算 FY26 Q4 收入 129 亿美元，-4%：Windows OEM 与设备 -7%。云在养公司，Windows 不再是增长引擎。

## 市场反馈与公司处置

这是比财报更能看行为习惯的一层。

1. **Windows Recall（2024）**  
   反馈：安全圈称其为间谍软件，本地截屏未加密。  
   处置：先坚称与 Copilot+ PC 同步上市，再推迟到 Insider，默认关闭、Windows Hello 才能开。2026 年内部仍在评估 Recall「当前形态失败」。  
   判断：会改，但第一次公开口径不诚实。

2. **Windows 11 Copilot 铺量（2024–2026）**  
   反馈：用户称 AI 膨胀、没人要。Windows 总裁 2025-11 提「agentic OS」遭大规模反对。  
   处置：2026-01 起收缩收件箱应用里的 Copilot 品牌、搁置通知层嵌入。  
   判断：压力足够大才会收。企业 Copilot 卖得出去，不能外推到消费者 Windows。

3. **Teams 捆绑（2020–2025）**  
   反馈：Slack 投诉、欧盟调查。  
   处置：EEA 先拆、2024 全球提供无 Teams 套件；2025-09 欧盟以承诺决定结案，而非罚金决定。  
   判断：监管压力下可让步，和 1990 年代反垄断后的模式同类。

4. **Xbox / Activision**  
   反馈：玩家要独占大作；员工要稳定；FTC 要可拆分的独立实体。  
   处置：对法院强调有限整合；交割三个月后以「重叠」为由裁 1900 人；2026-07 再裁、Xbox 侧约 3200 人、剥离最多五家工作室。公司称岗位不是被 AI 替换。  
   判断：对监管的「独立运营」与事后「去重叠」互相打架。FTC 2024-02 已书面指控食言。微软否认。**承诺对不上行为，记未兑现。**

5. **安全事故**  
   2021 Exchange Hafnium、2024 Midnight Blizzard（俄国家背景进微软自身租户）、2026 Entra ID CVE-2026-69836（CVSS 10，官方称野外利用后已在服务端缓解）。身份层是微软卖给企业的核心，也是反复出事的一层。处置以补丁和「用户无需操作」为主，透明度常被批评。

## 员工

利润创新高的同时连续收缩：2023 起多轮；2025 约 1.5 万人（两轮）；2026-04 自愿离职；2026-07 再裁 4800 人（约 2.1%）。公司称过去一年内部转岗超过 4000 人。Xbox 在天价并购后反复砍制作力量，对「对待员工」是明确减分。

## 董事会与准则

纳德拉 2014 起任 CEO，后兼任董事长，任期长、云转型可核对。资本回报持续（FY26 Q4 分红+回购 102 亿美元）。行为准则的污点不在会计造假，在**对监管与公众的可撤销承诺**：游戏独立运营、Azure 独占 OpenAI API、Recall 按期上市、每台 PC 都是 AI PC。后续都可以改，但第一次说法被证伪的次数偏多。

## 可信度与可持续（怎么读）

可信度问的是：说过的项目、并购、隐私、用工，事后能不能对上。可持续问的是：Azure/Office 能否在不透支员工与操作系统信任的前提下继续复合增长。微软的账本支持可持续；操作系统信任和游戏整合拖后腿。OpenAI 排他结束是战略风险，不是立刻的收入断裂——Azure 仍是训练与推理的主场地之一，且公司已持有 Anthropic 收益。

未完成的核验：10-K 全文逐项承诺表、OpenAI 新合同文本、Activision 对赌外的工作室清单、Entra 事故影响面。这些默认未核实。
