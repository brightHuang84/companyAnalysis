# 微软四十年事件台账（1986–2026）

截止 2026-09-07。对象：Microsoft Corporation，NASDAQ: MSFT，CIK 0000789019，财年截止 6 月 30 日。

## 这不是什么

微软 1986-03-13 上市，到今天满 40 年。要把这 40 年「里的细节都整理出来」并对照网上新闻，做不到也不应该假装做成：40 年的新闻稿、10-K、8-K、诉讼笔录和报道是几万条，不是一篇报告能穷尽的。

本次交出的是**物质事件骨干台账**：改变产品代际、大约 10 亿美元以上的并购、监管罚单与和解、被后续行为打脸的公开承诺、重大安全事故、大规模裁员。每条尽量对照公司新闻稿、美国司法部 / FTC / 英国 CMA / 欧盟委员会原文，以及路透、西雅图时报等当代报道。财务用来核验决策和产品有没有回收：当年公司研发与利润率作背景，对价、减值、罚金用已披露金额。单品研发年报不单列。

口径冲突单独写在「核验」栏，默认不把单源当最终事实。全部 8-K 正文还没有按贵州茅台那套 PDF 语料库下完。

91 条已全部补上当时背景、决策原因、决策目录、效果与财务回报，见 `reports/MSFT_event_decisions_1986_2026.md` 与 `data/issuers/MSFT/events_1986_2026.json`。可按年代逐条打开的台账在画布里。

## 总评（40 年看完再打分）

- **可信度 64（中）**：企业云和办公软件的交付，事后大体对得上数字。对监管、捆绑、游戏并购、Windows 消费端 AI 的第一次公开说法，多次被后续行为修正。模式是「先铺开、遇阻再收回」，不是「先说清边界再做」。这不是 2023 年以后才有的，1994 年同意令、2009 年浏览器选择屏、2013 年被罚执行失败，是同一条习惯。
- **可持续 71（中高）**：FY2026 营收 3318 亿美元，Azure 全年第一次超过 1000 亿美元，商业剩余履约义务 6780 亿美元。账本极强。风险在员工连续收缩、消费端 Windows / Xbox 失血、OpenAI 排他被拆后的模型供给。

七维（事件加权）：经营模式 84，董事会 76，行为准则 61，管理文化 58，消费者 54，用户 53，员工 46。

## 1986–1989：上市，图形界面还没赢

1986-03-13 纳斯达克上市，发行价 21 美元，融资约 6100 万美元，高盛承销。当时微软还不是后来的桌面垄断者：Windows 叠在 DOS 上，IBM 的 OS/2 合作还在，1987-04-02 宣布 OS/2，后来分道、自研 NT。

真正有后劲的一步是买产品而不是自研一切：1987-07 收购 Forethought，拿下 PowerPoint，Office 三件套开始成型。1988-03 苹果起诉 Windows 抄袭 Mac 界面，《纽约时报》1988-03-24 还披露过 1985 年协议；微软胜诉。

这一段的行为习惯已经能看见：用收购补齐套件，用授权和界面惯例扩大地盘，诉讼当经营成本。

## 1990–1999：Office 与 Windows 立住，IE 捆绑引来司法部

1990-05-22 Windows 3.0 才是图形界面真正普及的一天。同年 6 月 FTC 启动是否构成软件垄断的调查，委员 2-2 僵局未立案，案子转到司法部。1994-07 与司法部达成同意令：不得把其他产品绑死 Windows 授权。这条同意令后来被指违反，直接引出 1998 年大案。

1990-11-19（另有 1989-08-01 口径）Office 把 Word / Excel / PowerPoint 捆成套装价，打单一产品对手。1995-08-24 Windows 95 把 Internet Explorer 送进主流，桌面与上网大众化，IE 捆绑成为反垄断核心事实。1997-08-06 向苹果投资 1.5 亿美元，IE 成为 Mac 默认浏览器——救苹果，也把 IE 铺到对方机器上。1997-12-31 约 4 亿美元买 Hotmail，拿免费邮箱入口。

1998-05-18 司法部与 20 个州起诉：用 Windows 垄断维持并延伸到浏览器。1999-11-05 杰克逊法官公布事实认定。世纪案开审。Windows 98 把 IE 绑得更深。

这一段定下微软此后 30 年对监管的性格：**先造成既成事实，同意令只写行为救济，代码级捆绑能拖就拖。**

## 2000–2009：和解、Xbox、Vista，欧盟开始连续罚款

2000-01-13 盖茨把 CEO 交给鲍尔默。2000-04-03 杰克逊认定违反谢尔曼法，6-07 初审令拆成两家；上诉后拆分被推翻。2001-09-06 布什政府司法部宣布不再寻求拆分，改行为救济。2001-11-02 与联邦政府签署和解同意令：分享 API、设监察组，**不改捆绑代码本身**。部分州认为太轻，上诉至 2004 被驳。

产品上，Windows 2000 走企业线，ME 口碑差，XP（2001-10-25）成为此后近十年桌面主力。2001-11-15 Xbox 北美上市，用补贴换入主机市场。

欧盟比美国更愿意罚执行：

- 2004-03-24：4.972 亿欧元，媒体播放器捆绑 + 服务器互操作（欧委会 IP/04/382）。
- 2006-07：约 2.805 亿欧元，未执行 2004 互操作令。
- 2008-02-27：定期罚金 8.99 亿欧元，后减至 8.60 亿。
- 2009-12：浏览器选择屏承诺；后来 Win7 SP1 丢掉选择屏，2013 再罚。

消费端：Vista 2007-01-30 面向消费者，口碑差、升级慢。Zune 2006-11-14 没打过 iPod。2007-05-18 约 60 亿美元买 aQuantive，2012 年减值约 62 亿美元。2008-02-01 出价约 446 亿美元竞购雅虎，未成。搜索始终没翻盘。2008-09-02 Chrome 发布，IE 份额此后被削。2009-05-28 Bing 取代 MSN 搜索品牌。2009-10-22 Windows 7 修复 Vista 信任。

这一段的教训已经写在公开记录里：**美国和解保住了公司完整性；欧盟专罚「承诺了却不执行」。** 搜索和播放器证明：平台窗口错过，高价并购补不回来。

## 2010–2019：Azure 起步，手机失败，纳德拉改云

2010-02-01 Windows Azure 正式商用。当时远落后 AWS。这是后来 FY2026 全年 Azure 破 1000 亿美元的起点，中间隔了十六年。

手机是对称的失败：Windows Phone 晚于 iPhone / Android；2010 年 Kin 上市约 48 天停售；2011-02 与诺基亚结盟；2013-09-02 宣布约 72 亿美元买诺基亚手机业务，2014-04-25 交割；2015 年减记约 76 亿美元并裁员约 7800 人。Surface RT 2013-07-18 存货减记约 9 亿美元。Windows 8（2012-10-26）磁贴界面伤害桌面习惯。

2013-03-06 欧盟罚 5.61 亿欧元：违反 2009 浏览器选择承诺。承诺执行失败被罚，微软未上诉。这是「同意令 / 承诺决定」模式的一次公开打脸。

2011-05-10 宣布 85 亿美元现金买 Skype；2025-05-05 停服并入 Teams。2014-02-04 纳德拉任 CEO，战略改为云优先、跨平台，Office 上 iPad。此后做成的并购：2014 Mojang / Minecraft，2016 LinkedIn（262 亿），2018 GitHub（75 亿）。2016-11-02 Teams 上线，后来与 Office 套件捆绑，成为下一场欧盟案。2019 年起投资 OpenAI。

这一段把公司劈成两半：**云项目用十年对得上数字；移动和部分消费硬件用减记收场。** Skype 则是「买入口、养十年、品牌杀掉」的样本。

## 2020–2026：Win11、天价游戏、AI，消费端与员工还债

安全事故开始密集进入云叙事：2020-12 SolarWinds，2021-03 Exchange Hafnium，2024 Midnight Blizzard 进入微软自身租户，2026-08 Entra ID CVE-2026-69836（CVSS 10，影响面未独立核实）。身份层既是卖给企业的核心，也是反复出事的一层。

Windows 11（2021-10-05）用 TPM 设升级门槛。2020-08 洽购 TikTok 美国业务未成。2021-04-12 宣布约 197 亿美元买 Nuance。2022-01 宣布买 Activision Blizzard。

游戏是本台账里「承诺 vs 执行」最硬的一条：

- 2023-04-26 英国 CMA 禁止交易。
- 2023-10-13 在让出云游戏权利后交割，约 687 亿美元；对法院称可有限整合、可拆分。
- 2024-01 游戏部门裁约 1900 人（约 9%）。FTC 2024-02-07 致第九巡回上诉庭，指与庭上陈述冲突。微软否认食言。**承诺按未兑现记账。**
- 2026-07-06 再裁约 4800 人；Xbox 侧约 3200、剥离最多五家工作室。当季 Xbox 内容与服务 -10%。

AI 线：2023-01-23 宣布对 OpenAI 多年、数十亿美元投资（媒体口径约 100 亿）。2023-11-17 OpenAI 董事会罢免奥尔特曼，微软公开承接团队，数日后回归。2026-04 重订约：API 不再独占，OpenAI 可上 AWS 等；微软仍为大股东，排他承诺被拆。FY2026 业绩稿：Azure 全年破 1000 亿美元，M365 Copilot 付费席位超 3000 万，GitHub Copilot 5000 万用户。云项目对得上。

消费端 Windows 对不上第一次口径：2024 年 Recall 被批间谍软件，推迟上市、默认关闭、要 Windows Hello。2026-01 报道收缩 Windows 11 Copilot 铺量——属独家 / 匿名源，未逐条官宣。2025 年两轮合计约裁 1.5 万人，利润同期仍高增长。2025-09-12 欧盟 Teams 案以承诺决定结案（AT.40721 / AT.40873），未新处巨额罚金，换拆绑。Skype 2025-05-05 停服。

## 贯穿 40 年的四条习惯

1. **把新品绑进垄断入口。** IE、Media Player、浏览器选择屏、Teams，是同一动作换品类。监管到了会让；下一代品类再绑一次。
2. **对监管先承诺，执行再走样。** 1994 同意令 → 1998 大案；2009 选择屏 → 2013 罚款；Activision 庭上可拆分 → 交割后去重叠。承诺默认未核实，直到行为对得上。
3. **错过平台窗口就高价补，补不成就减记。** 雅虎未买成、aQuantive 减记、诺基亚减记、Skype 品牌杀掉、Activision 天价后裁员。企业云能做成；消费入口多次做不成。
4. **B2B 用十年兑现，B2C 口碑说改就改。** Azure 2010 商用到 FY26 才全年破 1000 亿美元。Vista→7、Win8→10、Recall 推迟，都是先伤信任再修补。

## 财务核验（决策与产品回报）

微软不披露 Windows、Office、Xbox、Copilot 的单品研发和单品利润。每条事件的财务栏分四句看：

1. **这条事件自己的钱**：并购对价、减值、罚金。没有单独科目就写未单列，不把全公司研发当成这条产品的开发费。
2. **和当年年报的关系**：营收、毛利率、营业利润率是微软整体数字，用来看当时买不买得起、罚得起。不是这条产品的利润表。
3. **这条产品线带给公司多少利润**：能核对的最细一级是分部营业利润。2006–2013 年有 Windows、Office、服务器、游戏/设备、搜索五条线；2016 年起只有生产力、智能云、更多个人计算三条。Azure、Xbox、Bing、PowerPoint 都没有单独营业利润。更细产品 10-K 给营收；席位增速在年报 KPI；绝对席位、公开标价和市场份额按年列在产品线页。2014–2015 年口径切过，相邻年不完全可比。
4. **事后回收**：后来这笔资产有没有变成可核对的分部利润，或有没有减记。

91 条财务回报判定：高回报 18，正回报 9，部分回收 14，减值收场 8，战略未兑现 15，监管成本 15，中性 10，未核实 2。

公司利润率轨迹（财年截止 6 月 30 日）：FY1986 营业利润率约 31%、净利率约 20%；FY1999 营业利润率约 51%（桌面垄断高峰）；FY2015 因诺基亚减记掉到约 19%；FY2026 营收 3318 亿美元、研发 356 亿、资本开支 1159 亿、毛利率 67.9%、营业利润率 46.8%、净利率 40.3%。

FY2026 分部营业利润：生产力 839 亿美元（利润率约 60%），智能云 570 亿（约 41%，Azure 全年破 1000 亿），更多个人计算 144 亿（约 27%；Windows OEM -7%，Xbox 内容与服务 -10%）。更细产品只有营收：服务器与云 1294 亿、Microsoft 365 商业 1020 亿、Xbox 218 亿、LinkedIn 198 亿、Windows 与设备 171 亿、搜索广告 152 亿。账本证明云和办公软件做成了，不能证明 Windows 消费 AI 与游戏并购兑现。

对得上价格的决策：PowerPoint（约 1400 万美元）、Office 套装、NT/Azure、Office 跨平台、GitHub（75 亿）、Minecraft（25 亿）、LinkedIn（262 亿，FY26 第四季仍 +12%）。吐回去的：aQuantive 近全额减值、诺基亚减记 76 亿、Skype 停服、Activision 687 亿交割后裁员且内容收入下降。欧盟罚金是垄断租金的部分返还，不是产品投资。

不要用 2018–2020 某些 XBRL 摘要里大约 300–380 亿美元的数字，那是季度量级被误读成年报。FY2016–FY2017 用 ASC 606 重述后比较数。
